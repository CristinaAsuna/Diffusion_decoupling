# 表征分析计划：D-only 去噪网络如何表示合成与真实侧位片（阶段 A，只做分析）

> 执行者：集群上的 coding agent。先读 `AGENTS.md`、`PROJECT_CONTEXT.md`、`docs/SIM2REAL_DIAGNOSIS.md`、README 第 5 节。
> 本计划不训练、不改默认预处理、不碰锁定的外部测试集。阶段 B（混合数据 SFT / 表征对齐）不在范围内。

## Context

已有诊断（`docs/SIM2REAL_DIAGNOSIS.md`）显示：真实片上预测 D 的 RMS 与合成相当（diffusion 0.999，Flow 0.863），没有全局幅度塌缩；但对强度、视野尺度、几何都敏感，真实失败主因未定，且没有真实 L/R 参考。用户的想法是：先看现有网络内部对真实片和合成片提取了什么表征（参考 SRA 论文 Fig.2 的"同一张图、不同时间步、不同层的 PCA"），再决定是否用混合数据 SFT 一个 DINO 或重建模型，并做表征对齐。

本计划回答三个问题：
1. 网络在哪些层、哪些噪声水平上能把真实片和合成片区分开（域信息留在哪里）？
2. 真实片的特征是否仍携带与合成片对应的解剖结构（语义是否被提取）？
3. 表征偏移是否能预测 D 的误差？也就是说，对齐表征有没有可能修复失败。

**数据量约束：集群上只有不到 20 张无标注真实片。** 所有真实域统计都以"图像"为单位做 bootstrap，报告 n 和置信区间，只称"观察"，不对一般真实域下结论。外部预训练权重（DINOv2）已获用户授权下载，仅限此项；不要下载数据集。

## 关键设计（先读，避免常见陷阱）

1. **网络是条件模型，输入是 `cat([F, y_t])`**（通道 0 是 F，通道 1 是 y_t；`diffusion.py:632`、`flow_matching.py:47`）。特征同时依赖 F 和噪声输入，所以必须控制 y_t，才能把"对 F 的表征"分离出来。定义三种提取模式：
   - **N 模式（主）**：y_t = 固定噪声 ε（所有图像、所有域共用同一个 seed 和同一张噪声图）。在高噪声时间步，y_t 几乎不含信息，特征主要反映 F。
   - **T 模式**：沿模型自身的采样轨迹取 y_t（真实片和合成片都可以），看推理时实际用到的表征。
   - **O 模式（仅合成）**：y_t 由真值 D 加噪得到，用来衡量"表征有多少来自噪声 D、有多少来自 F"。
2. **时间步**：diffusion 用 `model.gammas[t_idx]`，t_idx ∈ {990, 900, 700, 500, 300, 100}（gamma 小=近似纯噪声；零终端 SNR，t=999 的 gamma=0，避开边界）；Flow 用 t ∈ {0.99, 0.9, 0.7, 0.5, 0.3, 0.1}（t=1 是纯噪声）。把实际 gamma/t 值写进结果。
3. **网络调用**：`model.denoise_fn(torch.cat([cond, y_t], 1), g_or_t)`；`cond = clip(F_raw,0,6)/3-1`，真实片的条件用 `scripts/domain_stats.py::model_condition_from_source` 得到（它处理历史"先归一化再缩放"的顺序，并返回 mapped 和 normalized 两个版本）。
4. **hook 点**（UNet 输出，`consistent_cdm/model/models/unet.py`）：

   | 位置 | 模块 | 通道@分辨率 |
   |---|---|---|
   | 编码器 | `input_blocks[2]`、`[5]`、`[8]`、`[11]` | 64@256、128@128、256@64、512@32 |
   | 中间 | `middle_block` | 512@32 |
   | 解码器 | `output_blocks[1]`、`[4]`、`[7]`、`[10]` | 512@32、256@64、128@128、64@256 |
   | 输出 | 网络最终输出（D 预测） | 1@256 |

   `AttentionBlock` 走 `checkpoint(...)`，在 `no_grad` 下 hook 可正常触发。不要 hook 上采样后的 `output_blocks[2/5/8]`。
5. **token 约定**：把每层特征平均池化到统一的 32×32 网格；前景 mask 由 F（映射后）超过阈值的最大连通域给出（去掉背景、颈部以下、标尺文字）。每张图随机固定 256 个前景位置（归一化坐标，所有层、所有 t 共用），存 float16。完整 32×32 特征图只保存用于 PCA 可视化的少数图像。
6. **控制变量**：
   - 真实片主协议用 `quantile` 映射（与真实推理一致），`raw` 作为敏感性对照。
   - 内部基线：合成训练患者 vs 合成验证患者（患者级分离），给出"没有域差异"时各指标的零分布。
   - 随机初始化 UNet（同一结构、同一 hook）：负对照，给出"仅由像素统计造成"的可分性。
   - 合成退化桥接集（来自 `consistent_cdm/evaluation/degradations.py`）：`exponential`(k=1)、`blur`(σ=2)、`unsharp`(2)、`equalize`(1)、`scale`(0.7)、`noise`(0.1)，每种 1 个强度，覆盖 10 名验证患者。目的是看哪种合成偏移最接近真实片的特征偏移。
7. **checkpoint**：diffusion 用 step 65,000 的 `best_ema`，Flow 用 step 100,000 的 `last`（README 第 189 行）。历史 checkpoint 没有 `prepared_id`，走 `scripts/prepare_historical_diagnostics.py` 生成的仅诊断适配（不可用于训练），路径在本地 `artifacts/migration/sim2real_20261102/study.json`。若适配里取不到训练患者，用验证集患者级对半分（A/B）作为库和查询，并在报告里说明。

## 分析内容

### A0. 前置：特征对 F 与对噪声的依赖度
对每个 (层, t)：特征 `h(F, ε)`，计算 `h(F, ε')`（换噪声）和 `h(0, ε)`（F 置零）的相对变化。输出热图。用途：确认 N 模式确实主要反映 F；找出哪些时间步 y_t 开始主导。

### A1. 联合 PCA 网格（复现 SRA Fig.2 风格）
- 每个域取 3 张图（合成 3 + 真实 3，真实随机固定，不挑选）。
- 对每个 (层, t)：在两域的前景 token 上联合拟合 PCA，取前 3 个主成分映射为 RGB（全局 min-max，符号固定为最大绝对载荷为正）。
- 版面：行=层，列=时间步，分别画合成和真实；另画"各域单独拟合 PCA"版本。每格旁记 PC1–3 的方差占比。
- 注意：RGB 颜色在不同层之间没有对应关系，不要跨层比较颜色，只看空间结构是否连贯、是否分出解剖区域（颅骨、下颌、颈椎、软组织）。

### A2. 域可分性
- 在 token 上训练 L2 逻辑回归（标准化后降到 64 维），目标=域（合成/真实）。验证按图像分组（真实片留一，合成片同数量抽样），报告平衡准确率和 AUC，置信区间用图像级 bootstrap。
- 对每个 (层, t) 画曲线，并叠加三条参照：像素基线（F 局部块）、随机初始化 UNet、合成训练 vs 合成验证的零分布。
- 同时对合成退化集做同样的分类（退化 vs 干净），看哪种退化最像"真实 vs 合成"的可分性。

### A3. 分布距离
Fréchet 距离和无偏 MMD²（RBF，中位数带宽），在图像池化特征和 token 特征上计算，用合成 vs 合成的零分布归一化；bootstrap 同上。

### A4. 无标签语义对应
- **位置检索**：对每个真实 token（位置已按前景包围盒归一化），在合成 token 库里取 cosine 最近邻，计算两者归一化坐标的中位误差。对照：随机邻居（上界）、合成验证→合成训练（下界）、真实→真实留一。
- **跨域聚类**：在两域联合 token 上做 k-means（k=8、12），报告聚类与域的互信息（越低说明混得越好），并画聚类图，人工判断两域中同一类是否落在相似的解剖区域。
- 局限（写进报告）：位置只是解剖对应的粗略代理，真实片视野不同会引入误差；这里没有关键点真值，所以不声称"语义已提取"，只比较相对关系。

### A5. 表征偏移与 D 误差的关系（最关键）
- 对合成退化集（真值已知）：每张图计算"特征偏移" = 该图 token 到合成训练库的 kNN 距离（在每个层、每个 t），同时计算 D-NMAE（复用 `consistent_cdm/runtime.py::stress_test` 的计算方式和 `branch_metrics`）。
- 汇报跨 (退化, 强度, 患者) 的 Spearman 相关及其置信区间，找出预测 D 误差最好的层和 t。
- 把真实片放到同一偏移坐标上，说明它们落在哪些退化的范围内。**这只是类比**，不能当作对真实片的误差估计，报告里必须这样写。
- 结论用途：偏移与误差相关性强，说明对齐表征有望改善；相关性弱，说明 D 的失败不在特征提取，阶段 B 的收益存疑。

### A6. 外部参照：DINOv2
- 已授权下载：DINOv2 ViT-S/14 与 ViT-B/14，仅这两个权重。记录来源 URL、版本和 sha256，放在 `artifacts/` 下，不入库。
- 单通道图复制成 3 通道，缩放到 448×448（32×32 token），与 UNet 的统一网格对齐。
- 对 DINOv2 重复 A1、A2、A3、A4。目的：看一个强基础编码器是否把真实和合成侧位片看成同一类东西，并作为"潜在对齐目标"的可行性参照。

## 预先写下预期（运行前写入报告，运行后对照）
- H1：浅层（`input_blocks[2]`）两域几乎完全可分（AUC≥0.95），与像素基线接近。
- H2：深层和较高噪声下可分性下降，但不会降到零分布水平。
- H3：位置检索中，真实→合成误差大于合成→合成，但明显小于随机。
- H4：DINOv2 的跨域可分性低于 UNet 浅层。

## 结果解读表（决定下一步，不在本计划内执行）

| 观察 | 含义 | 下一步 |
|---|---|---|
| 各层可分性都≈1，真实→合成检索接近随机，A5 相关性强 | 网络没有为真实片提取可用表征，且偏移确实对应 D 误差 | 阶段 B 有依据：混合数据 SFT + 表征对齐 |
| 深层域混合较好，检索正常，但 D 仍错 | 失败不在特征提取，更可能在几何或解码 | 回到几何和强度诊断，不做对齐 |
| A5 相关性弱 | 表征偏移不预测 D 误差 | 对齐的收益存疑，先建立独立参考 |
| DINOv2 也把两域完全分开 | 基础模型本身没有对应的语义空间 | 对齐目标要先在混合数据上适配 |

## 风险提示
- 真实片不足 20 张，图像级统计的区间会很宽；任何"显著"措辞都要以区间为准。
- PCA 颜色和聚类编号没有跨层含义；不要把"看起来分得开"当成语义已提取。
- 历史权重的 L/R 存储顺序未验证，本分析不涉及左右归属，不得据此改称解剖左右。
