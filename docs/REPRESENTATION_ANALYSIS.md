# 冻结模型表征分析：阶段 A

## 范围

对冻结的 D-only diffusion（step 65,000）、Flow（step 100,000）和 DINOv2 ViT-S/14、ViT-B/14 做表征诊断。使用36名合成训练患者、18名留出验证患者及随机固定的18张真实图像；10名验证患者的标准视图用于退化对照。真实来源图像是否互相独立、设备几何和真实 L/R 均未知。未训练模型、改默认预处理或使用锁定测试集。

N 模式在六个噪声水平共用同一张噪声图；O 仅在合成目标上加噪；T 跟踪原生采样调用并记录实际时间。低噪声 N 是离轨迹诊断。真实条件以 quantile 映射为主，raw 为敏感性对照。A0 的零条件是归一化后的0，对应映射 Full 约3，不是空图。最终 U-Net 输出是 v 或 velocity，不直接称为 D。

## 主要观察

- **H1 部分符合。** 两种模型的浅层在六个噪声水平上，真实/合成图像域探针 AUC 均为1.00（每域18张；图像级 bootstrap 95% CI [1.00, 1.00]，区间条件于已有折外预测）。与像素基线“接近”的等效界限未预先定义，不能断言两者等效。
- **H2 的指定高噪声比较未见下降。** Diffusion 的 t=990、Flow 的 t=0.99 下，浅层和中间层 AUC 均为1.00。结果并非所有层都如此：diffusion 最终单通道输出在 t=990 的方向性 AUC 为0.179（95% CI [0.052, 0.330]），同一验证折内为5/18（条件式配对 bootstrap 95% CI [0.111, 0.500]）；不能把低于0.5的 AUC 自动解释成域混合或不存在域信息。
- **H3 方向大体一致，但位置只是代理。** 两模型120个层/时间切片中113个满足“合成→合成位置误差 < 真实→合成 < 随机邻居”的点估计顺序；切片不是独立样本。DINO-S/B 的真实→合成归一化位置误差中位数分别为0.120（95% CI [0.109, 0.139]）和0.116（[0.097, 0.125]），随机对照约0.481。没有真实 landmark 真值，不能据此证明解剖语义对应。
- **H4 未观察到更低的 DINO 域可分性。** 两个 DINO 的 AUC 均为1.00（每域18张，条件式 bootstrap CI [1.00, 1.00]），与浅层 U-Net 点估计相同；这也不能证明 DINO 不含有用结构信息。
- **偏移与 D 误差的关系取决于比较方式。** 预先指定的高噪声中间层中，10名患者的 quantile 退化池化 Spearman ρ：diffusion −0.117（95% CI [−0.497, 0.472]）、Flow −0.147（[−0.466, 0.495]）；患者内相对干净图的变化分别为0.418（[0.243, 0.604]）和0.496（[0.333, 0.661]）。后者仍可能受退化类型影响，不能证明表征对齐会改善重建。真实图像只放在偏移坐标作类比，没有真实误差估计。

高噪声 A0 中，两模型各10个被测层的平均条件变化均大于换噪声变化（仅6个预选代表图像）。scale=0.7 的 quantile 映射因分位数退化跳过10例，raw 对照保留。MMD 域比较和合成参照使用同一个仅由训练参考估计的带宽；合成训练参照与参考库重叠，是描述性参照，不是独立零分布。

## 解释边界

跨域可分性、PCA 颜色、聚类和坐标检索不能单独证明特征缺少解剖语义，也不能判定阶段 B 会成功或失败。折外 AUC 汇总了不同模型折的分数；同折配对排序作为敏感性对照，折间训练集高度重叠。所有区间均条件于固定权重、噪声、已拟合参考及具体抽样；18张真实图像未确认来自18名独立患者。当前自动前景掩码可能包含颈部和器械标记。

[DINOv2 官方源码](https://github.com/facebookresearch/dinov2)版本 `7764ea0f912e53c92e82eb78a2a1631e92725fc8`；ViT-S/14、ViT-B/14 权重 SHA256 分别为 `b938bf1bc15cd2ec0feacfe3a1bb553fe8ea9ca46a7e1d8d00217f29aef60cd9`、`0b8b82f85de91b424aded121c7e1dcc2b7bc6d0adeea651bf73a13307fad8c73`。权重与完整中间结果仅保存在本地；本仓库提供[精简图文报告](REPRESENTATION_REPORT.md)。

## 实现摘要

本地实现通过 U-Net 前向 hook 提取编码器、中间层、解码器和原生输出；特征池化至 32×32，并在每图固定前景位置采样。PCA、图像分组交叉验证、Fréchet/MMD、位置检索和患者级 bootstrap 在 CPU 上执行；MMD 比较共享训练参考带宽。报告只展示汇总图，完整代码、特征缓存、权重和病例级结果不属于本次提交。
