# 合成到真实诊断总结

状态：**计算诊断完成，真实分解准确率仍未验证**。更新：2026-11-03。

## 要解决的问题

历史模型在合成投影上以256×256训练，真实512×512侧位片缩到256后推理，
视觉效果不理想。本次检查这种失败是否表现为全局D幅度塌缩，以及强度映射、
FOV/尺度和投影几何是否影响差异预测。数据来源与队列边界见
[项目背景](../PROJECT_CONTEXT.md#数据从哪里来)。

使用既有 diffusion/Flow EMA 权重、固定随机种子和原患者划分；没有新训练，
也没有使用锁定的外部测试集。实验包括合成验证基线、raw/quantile退化对照、
真实输入约定扫描，以及先复现原投影再改变名义SAD/SID的几何对照。

## 主要结果

| 指标 | Diffusion | Flow |
|---|---:|---:|
| 合成验证D-NMAE（Full/2基线为1） | 0.4891 | 0.4895 |
| 真实/合成预测D的平均RMS比 | 0.999 | 0.863 |
| 几何对照D-NMAE：原几何→1520/1670、固定裁剪 | 0.484→0.661 | 0.501→0.686 |

真实/合成RMS比是两个队列输出幅度的描述性比较，**不是配对真实误差**。
几何表来自预先选定的小样本，改变SAD/SID时也沿用相应detector pitch规则；
该名义设置不是实测真实设备参数，不能据此作设备或临床结论。

1. **没有发现普遍接近零的全局D输出。** Diffusion真实输出幅度与合成预测相近，
   Flow约低14%。L/R看起来像Full/2，不能单独证明D塌缩；局部结构仍可能错误。
2. **幅度恢复不等于重建正确。** 强指数压缩可显著降低raw输出的D幅度；
   quantile映射恢复幅度后，D误差仍高于干净输入。它不是物理线性化或设备标定。
3. **模型对FOV/尺度和几何敏感。** 受控变化能增加D误差，且D幅度可能同时增加。
   真实输入反相、朝向、缩放扫描没有提供通过提高全局幅度解决失败的证据。
4. **真实失败主因尚不能唯一确定。** 当前结果支持受控敏感性，不能证明真实厂商
   后处理、物理几何或分辨率中的某一项就是主因，也未建立新的默认预处理。

## 对后续工作的约束

- 真实L/R参考、实际SAD/SID和近探测器侧别仍缺失；人工轮廓测量尚未完成。
  下一步应优先取得独立参考或合格任务标注，而不是按输出幅度最大值选择输入变换。
- 保留D空间误差、identity和Full/2对照；高Full/L/R PSNR或精确和一致性不足以证明拆分正确。
- `energy_ratio`实际是RMS比。quantile无定义的输入应记为跳过，不能补零作为模型失败。
- 历史权重的患者划分、固定D尺度和存储通道语义必须保留，不能伪造sidefix来源；
  NIfTI体积应先应用header缩放再解释为HU。工程复现通过不等于真实准确率通过。
